Envenom - Minecraft Mod

This is my most recent mod for Minecraft 26.2. It's a cool mod that allows players to tip their weapons with potion effects just like you can tip arrows. I also went with an assasin theme and made it so you can apply potion effects to food. One potion splits it's effect with up to 8 pieces of food. Only the person who applied the effect can see that there is an effect, but if you have advanced tooltips enabled, you can see the effect on the food. For those who are not familiar with advanced tooltips, you can enable it with F3 + H.

This is only my second Mod, so I am making good progress towards my goal of 50 mods by the end of October this year. I might use this mod in the server I run with my friends, but mostly this mod is here because I was not able to find a mod that did the same thing. If you want to try it out, use the link below.
