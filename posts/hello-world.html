Hello World

I've been meaning to set up a place to write for a while, and the friction was always the same: picking a platform, learning its conventions, and then discovering it wanted me to write in its editor rather than mine. So this is about as simple as it gets — plain HTML files in a folder, served by GitHub Pages. No build step, nothing to keep updated, nothing to break.

The plan is to use this mostly as a notebook. Things I've built, problems that took longer to solve than they should have, and the occasional longer piece when something is worth thinking through properly.

How this works

Every post is a standalone file in posts/. To publish one I copy posts/_template.html, write into it, add a line to the index, and push. That's the whole workflow: 

git add .
git commit -m "New post"
git push

Thirty seconds later it's live. If it turns out I want tags, or an archive page, or syntax highlighting, I can add them later — but I'd rather start with the smallest thing that works than build scaffolding for posts I haven't written yet.
