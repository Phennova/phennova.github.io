Team Cards - Minecraft Mod

I run a small Minecraft server for a few friends. We like to PvP a lot, though we often get bored of vanilla Minecraft fighting and mechanics. I created this mod to help organize the teams and to spice up combat. I call the mod Team Cards.

How Team Cards works

There are a configurable number of teams. Each team gets dealt a card during team creation. There are 5 cards: Hearts, Clubs, Spades, Diamonds, and Joker. Each team gets unique buffs and special abilities tied to which suit they have and the level of their suit. To unlock more abilities, teams have to craft totems to level up their card. At max level, each card is the strongest it can be, and all buffs gained from previous levels stack.

Everything in this mod can be configured in the server config file that is automatically created upon restarting the server with the mod installed. This mod runs on NeoForge, which is the modernized fork of Forge. The link to download the mod and try it for yourself is down below. The source code for this project is not yet public, but if it is requested I can release it.
